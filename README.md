## Overview

Yantra is a frontend prototype shaped for startup-style presentation. It is built to showcase product ideas, services, workflows, and modern UI execution in a concise web experience.

## Quick Start

```powershell
git clone https://github.com/akyourowngames/Yantra.git
cd Yantra
npm install
```

## Run Locally

```powershell
npm run dev
Open http://localhost:3000
```
